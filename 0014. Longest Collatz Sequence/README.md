## Problem
**Which starting number, under one million, produces the longest collatz sequence chain?**

## What is Collatz Sequence ?
**The Collatz sequence starts with a positive integer and proceeds according to the following rules:**
- If the number is even, divide by 2. 
- If the number is odd, multiply by 3 and add 1.
**These operations are repeated to form a sequence. The Collatz Hypothesis suggests that this sequence will eventually reach 1 at each starting number.**

## Result
**837799**
