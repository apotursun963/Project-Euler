## Problem
**What is the largest n-digit pandigital prime that exists?**

## What is Pandigital Prime Number ?
**A pandigital number is a number that contains all the digits from 1 to 𝑛 only once each. for example: 2143 is a 4-digit pandigital number (containing the digits 1, 2, 3, 4).**

## Result
**7652413**
