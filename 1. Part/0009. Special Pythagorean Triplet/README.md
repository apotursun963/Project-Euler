## Problem
**There is exactly one Pythagorean triplet that satisfies the condition `a + b + c = 1000`. Find this triplet and calculate the product `a x b x c = ?`**

## What is Pythagorean Triple
**Pythagorean Triple, It is a set of three natural numbers (positive integers) that satisfy the Pythagorean theorem between the side lengths of a right triangle. The Pythagorean Theorem states that in a right triangle, the sum of the squares of the legs equals the square of the hypotenuse.** 

Formula: `a^2 + b^2 = c^2`

-  `a` an `b` represent the perpendicular sides of the triangle, while `c`  represents the hypotenuse (the longest side of the triangle).

### Examples
- (3, 4, 5) is a Pythagorean triple because:
    `3^2 + 4^2 = 9 + 16 = 25 = 5^2`

## Result
**31875000**
